## Changes

**`src/storage/edges.rs`** — added `delete_edges_by_type(conn, edge_type)`, a single `DELETE FROM edges WHERE edge_type = ?1` alongside the existing per-source delete.

**`src/index/code_graph/mod.rs`** — `sync_code_edges` now deletes all `calls`/`imports`/`extends` edges (new `STRUCTURAL_EDGE_TYPES` const) before inserting the freshly extracted set. Structural edges are derived state rebuilt wholesale from the AST; previously insert-only (`INSERT OR IGNORE`) meant edges for removed calls/imports persisted across every reindex. `references` edges are untouched — file sync owns those (`sync_references` in `files/refs.rs` already does per-source delete+reinsert).

**`src/files/sync.rs`** — `get_file_backed_entities` now filters `type IN ('observation','rule','knowledge')` instead of `file_path IS NOT NULL`. Code entities also set `file_path` (it's their source path, not a `.cogz/` file), so file sync was spuriously marking every code entity stale on each `cogz index`/`reindex` run before code sync re-activated them.
