## Summary

**Bug:** In `DigestAuth._build_auth_header`, when the server challenge has no `qop` (RFC 2069 mode), `digest_data` included `HA1` — but `HA1` is also prepended when computing `key_digest`, so the response was `digest(HA1:HA1:nonce:HA2)` instead of RFC 2069's `digest(HA1:nonce:HA2)`.

**Fix:** Removed the duplicated `HA1` from the `qop is None` branch. [_auth.py:281-286](file:///home/andy/cogz_bench/replay_tmp/cogz_replay_99cba6ac_t0bb55ub/httpx/_auth.py)
