## Changes

**New file** `src/index/sync/normalize.rs` — `normalize_content(content, language)`:

- Strips `//` and `/* */` comments for C-like languages (rust, go, javascript, typescript, tsx); `#` comments for python and bash.
- String-literal aware: a single-pass state machine tracks `"`, `'`, `` ` `` delimiters (with `\` escapes) so comment markers inside strings are preserved. Rust/Go exclude `'` (lifetimes/rune literals); Python gets `"""`/`'''` triple-quote handling; block comments preserve their internal newlines.
- Whitespace normalization: trailing whitespace trimmed per line, blank lines dropped. Internal whitespace untouched, so `a+b` vs `a + b` still hashes differently.

**`src/index/sync/mod.rs`** — `convert_entities` now hashes `normalize_content(&ce.content, language)` instead of raw content, taking the language from `ce.properties["language"]` (set by every tree-sitter extractor). Stored `entity.content` stays raw — only the change-detection hash is normalized.
