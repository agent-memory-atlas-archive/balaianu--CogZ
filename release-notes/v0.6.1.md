## CogZ v0.6.1

Patch release: security fixes in the TLS stack, an honest MSRV, and a
CI fix for macOS runners.

### Highlights

- **rustls 0.23.46** — fixes RUSTSEC-2026-0346 and RUSTSEC-2026-0349,
  flagged by `cargo audit`. Release binaries are built with the fixed
  version; source builds and `cargo install` pick it up via the
  lockfile.
- **hf-xet pinned to 1.5.4** — the locked xet 1.6.0 stack used
  `floor_char_boundary` (stable in Rust 1.90), silently breaking the
  declared 1.88 MSRV. The pin removes the 1.90-only API.
- **File-size ratchet portable to bash 3.2** — `declare -A` crashed
  the check on macOS runners, which ship bash 3.2. Aggregation moved
  to awk with identical GROWTH/OVER/STALE semantics. This also fixes
  the local pre-commit hook (`.githooks`) for contributors on macOS.

### Upgrade notes

- **MSRV is now Rust 1.89** (was 1.88). A correction, not a new
  requirement: the 0.6.0 lockfile already pulled crates needing
  ≥1.89 (redb 3.1, konst 0.4), so the 1.88 declaration was untrue.
  Binary users are unaffected; `docs/dev/building.md` is updated.
- No schema, file-format, or config changes — drop-in binary swap;
  existing `.cogz` data is untouched.
