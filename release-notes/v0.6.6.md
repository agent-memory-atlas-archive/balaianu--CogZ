## CogZ v0.6.6

Patch release fixing hook-consumer compatibility: `--hook-json`
silent-skip now emits empty stdout instead of a bare `{}`.

### Highlights

- **`--hook-json` no-ops are truly silent.** When no `.cogz/` exists,
  no index database exists, or an event has nothing to inject,
  `capture-event` now prints nothing at all instead of `{}`. Absent
  stdout is the portable no-op across hook consumers; a bare `{}`
  parses as a valid JSON object but matches no strict output schema —
  Devin's `post_compact` rejected it with
  `invalid post_compact JSON output` on every run from a non-indexed
  working directory.
- **Serialization-failure fallback goes silent too.** If the response
  envelope ever fails to serialize, the fallback is now empty stdout
  rather than `{}` — emitting malformed-shaped output in an error
  path is the same bug class.

### Upgrade notes

No config or data migration needed. Hook consumers that treated `{}`
as a no-op (Claude Code, Cursor, Copilot) already treat absent stdout
identically, so behavior there is unchanged. For Devin, hook commands
that previously logged a parse error now silently no-op as intended.
