sync_single_file checks file_path.starts_with(".cogz/") — a hook passing `.cogz\knowledge\x.md` on Windows misses the prefix, falls to cogz_dir.join() producing a nonexistent `.cogz\.cogz\...` path, exists() returns false, empty SyncResult — the file_save hook silently does nothing. Also: resolve_file_path in stale_flagging uses starts_with(".cogz") with no separator (looser than the ".cogz/" check elsewhere — inconsistent). Windows is a supported release target. Verified 2026-09-14. Backlog item 30.
