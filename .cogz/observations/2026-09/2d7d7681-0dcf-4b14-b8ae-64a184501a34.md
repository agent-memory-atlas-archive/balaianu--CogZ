The search pipeline in cogz search always uses the knowledge model (bge-base) for query embedding, never the code model (CodeRankEmbed). This means the CodeRankEmbed query prefix is implemented in embed_query() but never exercised in production. The code model is only used for embedding code entities during indexing. This matches the Python CogZ benchmark finding that the knowledge model was preferred for natural-language queries even on code-heavy repos.
