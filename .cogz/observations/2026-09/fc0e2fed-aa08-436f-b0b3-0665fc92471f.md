Embedding absolute cosines are not comparable across the two models: bge knowledge real matches ~0.7-0.8 vs CodeRankEmbed ~0.3-0.5. Absolute-strength channel merge collapses the code channel (benchmark: code P@5 -> 0.0). Within-batch gradient separates negatives from real queries cleanly (<=0.015 vs >=0.024 max gradient) but fails as a merge weight for the same reason (code distances cluster too tightly). Validated config: detect merge + min_relevance 0.05 + silence_threshold 0.02 + edge-weighted expansion (strongest-first BFS claiming).
