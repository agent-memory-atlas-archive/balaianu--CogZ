Technique that proved the hybrid.rs → hybrid_helpers.rs extraction behavior-preserving: run identical MCP `cogz mcp-stdio` search calls through the pre-refactor release binary and the post-refactor debug binary against the *same* corpus DB; diff (id, relevance, graph_path) tuples. 12/12 queries byte-identical.

Two traps the technique must avoid:
- **Comparing against a recorded benchmark run** — the DB drifts across `reset`+`index` (KNN distances wobble ±.0004, boundary entities swap). A rank-boundary diff vs a recorded run is DB state, not code. Re-run the OLD binary on the CURRENT DB to discriminate.
- **CLI output** — pagination/formatting noise; raw MCP `tools/call` JSON over stdio gives exact comparable tuples.

Cost: ~30 lines of python (initialize → initialized → tools/call → read line), reusable for any retrieval refactor.
